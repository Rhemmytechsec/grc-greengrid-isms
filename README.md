# GreenGrid Renewable Energy Management ISMS Project

## Overview
This project presents a complete Information Security Management System (ISMS) documentation package developed for a fictional renewable energy company.

The project focuses on:
- ISO/IEC 27001:2022
- Operational Technology (OT) Security
- SCADA Security
- Vendor Risk Management
- Critical Infrastructure Protection
- Governance, Risk, and Compliance (GRC)

---

## Project Objectives

- Develop an ISMS framework for critical infrastructure
- Protect SCADA and OT systems from cyber threats
- Implement cybersecurity governance controls
- Improve vendor and third-party security management
- Align with ISO 27001 and IEC 62443 standards

---

## Deliverables

- Organizational Context Document
- Information Security Policy
- Vendor & Third-Party Risk Management Policy
- Performance Monitoring & Measurement
- Executive Summary

---

## Technologies & Concepts

- SCADA Systems
- ICS/OT Security
- ISO 27001
- IEC 62443
- MFA
- VPN Security
- AES-256 Encryption
- Incident Response
- Risk Management
